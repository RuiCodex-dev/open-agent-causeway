# Causeway — the agent that explains *why*, with evidence

**Open Agent Hackathon 2026 · Track 02: The Agent That Can Explain Why · Team Rui Codex**

> Status: under construction during the build window (22–27 October 2026). This README is completed as the
> components land; nothing here describes a feature before it exists in the code.

Small-business owners ask *why* every quarter — why did our margin fall, why are sales down — and have no
analyst to answer. Causeway investigates the question the way a careful analyst would: it proposes rival
explanations, tests each one with real queries against the owner's ledger and public Eurostat statistics
federated through **Zetaris**, lets a sceptic agent attack every "supported" verdict, re-checks every number
before it is shown, and remembers what the owner has confirmed (**Meterless** engines). Reasoning roles run on
**NVIDIA Nemotron** through a **Meterless Runtime** provider seam. Built in **Cursor**.
